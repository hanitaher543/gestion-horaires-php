# Gestion des Horaires de Travail (POO - PHP)

Ce projet est une petite application PHP en Programmation Orientée Objet (POO) permettant de :

- Ajouter des heures de travail pour chaque employé
- Afficher les horaires hebdomadaires
- Calculer le total des heures
- Vérifier le respect des heures contractuelles

## Fonctionnalités

1. Ajouter des heures par jour (lundi à vendredi)
2. Voir les horaires d’un employé
3. Calculer le total des heures
4. Vérifier le contrat horaire

## Technologies

- PHP
- HTML (formulaire)
- Sessions PHP (stockage temporaire des données)
- XAMPP (ou tout serveur local compatible)

## Utilisation

Lancer le fichier `index.php` via votre serveur local (ex: `http://localhost/gestion-horaires-php/index.php`).
